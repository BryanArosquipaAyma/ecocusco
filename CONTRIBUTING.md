# Flujo de trabajo en Git

| Elemento         | Convención                                                               |
|------------------|--------------------------------------------------------------------------|
| Rama main        | Versión estable y entregable; solo recibe cambios desde develop          |
| Rama develop     | Integración del trabajo del equipo                                       |
| Ramas de trabajo | feature/RF-11-registro-entrega, fix/…, docs/…; una por requerimiento     |
| Cambios          | Todo entra por pull request con al menos una revisión de otro integrante |
| Commits          | Formato convencional: feat:, fix:, docs:, chore:                         |
| Tareas           | Cada requerimiento RF-xx es una tarjeta en GitHub Projects               |
