# EcoCusco

Plataforma web (PWA) que premia el reciclaje en el distrito de Santiago, Cusco.

## Problema
Los vecinos no saben cuándo pasa el camión recolector ni dónde reciclar, y no tienen un incentivo para separar sus residuos.

## Solución
EcoCusco permitirá:

- Consultar rutas y horarios de recojo.
- Reportar puntos críticos de basura con foto y ubicación.
- Encontrar puntos limpios en un mapa.
- Ganar puntos por reciclar (validados con QR) y canjearlos en comercios afiliados o retirarlos en soles por Yape/Plin.

## Roles
Ciudadano, comercio afiliado, operador de punto limpio, personal municipal y administrador.

## Tecnologías previstas
React + Vite (PWA), Tailwind CSS, Leaflet, Node.js + Express, Prisma, PostgreSQL (Supabase), JWT.

## Estructura
- `frontend/` Aplicación React (PWA)
- `backend/` API REST en Node.js
- `docs/` Documentación del proyecto y diagramas
